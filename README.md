## ▶️ How to Run

### 1. Clone the repository

```bash
git clone <repository-url>
```

### 2. Open the required program

For example:

```text
01-Basic-Programs/
```

### 3. Compile the C program

Using GCC:

```bash
gcc program.c -o program
```

### 4. Run the program

On Windows:

```bash
program
```

or:

```bash
.\program.exe
```

On Linux/macOS:

```bash
./program
```
